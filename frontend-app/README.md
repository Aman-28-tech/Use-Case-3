# Punjab Sports Mart — Store Associate Mobile App (React Native)

Mobile assistant for retail store associates (Cashier, Store Manager, Inventory Associate).

## Features
- **Instant Triage**: Report POS errors, bat stockouts, seam defects, and return overrides.
- **Offline / Local Runbook**: Instant access to SOP runbooks and policy citations.
- **Manager Approvals Inbox**: Mobile push notifications and 1-tap sign-offs for P1/P2 tickets.
- **Connects to**: Local Node.js Backend API at `http://localhost:5000/api/v1`.

## Quick Start
```bash
npm install
npm start
# or npm run web to preview in browser
```
